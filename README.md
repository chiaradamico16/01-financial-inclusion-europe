# Financial Inclusion in Europe

## Motivation
This project builds on the extensive literature concerning financial stability and inclusion, a key element for economic development and poverty reduction. 
While the Euro Area is amongst the richest in the world, still disparities persist. Thus, this project aims at exploring the distribution of access to financial instruments to uncover how financial inclusion differs across European countries, with a specific focus on identifying potential gaps related to gender, age, education, and income.
Understanding these disparities is crucial when designing policies to ensure access to financial services to all European citizens. 

## Research Question
How does financial inclusion differ across European countries?

## Dataset
The data used in this project is sourced from the World Bank's Global Findex Database 2021. It is composed of interviews with individuals aged 15 or older. The standardized questionnaire covers access to financial instruments, the use of digital payments, savings, credit, and financial resilience.
The data are weighted to represent the national adult population and cover 123 economies worldwide, with approximately 128,000 individuals interviewed in 2021.
